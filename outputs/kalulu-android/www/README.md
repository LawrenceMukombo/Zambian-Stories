# Kalulu Reader

Serve this folder over HTTP: `python -m http.server 8080`. It is an offline-first PWA prototype ready to wrap with PWABuilder or Capacitor after adding final branding, icons, signing, privacy policy, and store screenshots.

## Opening the reader

You can now double-click `index.html` for a local preview. For installability and offline caching, serve the folder over HTTP and use `http://localhost:8080`.
